COMO ATUALIZAR O LABORATÓRIO

1. Abra a pasta do seu repositório do GitHub.
2. Substitua os três arquivos antigos pelos três arquivos desta pasta:
   - index.html
   - style.css
   - script.js
3. Atenção: mantenha exatamente esses nomes, sem (4), (7) ou outros números.
4. Salve/ faça commit e aguarde o GitHub Pages atualizar.
5. Abra o site e pressione Ctrl + F5 para recarregar sem usar o cache.

Os três arquivos já estão conectados entre si. Não copie o conteúdo para dentro de outros arquivos.
