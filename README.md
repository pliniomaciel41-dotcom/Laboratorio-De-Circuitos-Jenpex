# Laboratório Virtual de Circuitos Elétricos

Projeto educacional desenvolvido com HTML, CSS e JavaScript.

## Como abrir
1. Extraia os arquivos.
2. Abra `index.html` em um navegador atualizado.

## Modos disponíveis
- **Montagem livre:** adiciona componentes à área de montagem, permite abrir/fechar o interruptor, limpar a montagem e calcular corrente e potência usando a Lei de Ohm.
- **Circuitos de questões:** apresenta dois esquemas prontos (um circuito em série e um circuito misto série-paralelo), com valores e resolução explicada.

## Limitação importante
A montagem livre é uma representação didática simplificada: os componentes são exibidos na ordem de inclusão e os fios são visuais, sem conexão elétrica individual entre terminais. A aba de circuitos de questões apresenta exemplos predefinidos, não um editor livre de esquemas.
