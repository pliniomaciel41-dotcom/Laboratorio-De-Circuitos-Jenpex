# Laboratório Virtual de Circuitos Elétricos

Projeto educacional feito com HTML, CSS e JavaScript.

## Como abrir
1. Deixe `index.html`, `style.css` e `script.js` na mesma pasta.
2. Abra `index.html` em um navegador atualizado.

## Modos disponíveis
- **Montagem livre:** representação didática simples com componentes e desafios.
- **Circuitos de questões:** exemplos prontos de circuito em série e circuito misto, com resolução.
- **Montagem avançada:** permite adicionar e arrastar componentes, conectar terminais com fios e analisar circuitos resistivos simples.

## Como usar a montagem avançada
1. Clique nos botões para adicionar fonte, resistor, lâmpada e interruptor.
2. Arraste as peças para posicioná-las na bancada.
3. Clique em um terminal redondo e depois no terminal de destino para criar um fio.
4. Selecione um resistor ou lâmpada para alterar sua resistência.
5. Dê duplo clique no interruptor ou selecione-o e use o botão para abrir/fechar.
6. Clique em **Analisar circuito**.

## Limitações didáticas
A análise avançada reconhece circuitos resistivos redutíveis por associações em série e paralelo, com uma única fonte ideal. Redes mais complexas podem ser reconhecidas como fechadas, mas não terão resistência equivalente calculada automaticamente. Não modela componentes reais, corrente alternada, diodos, capacitores ou comportamento térmico da lâmpada.
